# Shared infra (`src/shared/infra`)

The only place allowed to import third-party libs directly (ESLint `no-restricted-imports` blocks them elsewhere; exceptions: `zod`, `nestjs-zod`, `@nestjs/*`, `jest`, `@faker-js/*`). Pattern: interface in `types.ts`, implementation in a sub-folder, bound to a string token in `shared.module.ts`, tests + mocks alongside.

## Environment variables (`env/env.schema.ts`)

`NODE_ENV`, `PORT`, `CORS_ORIGINS`, `DB_HOST`, `DB_NAME`, `DB_PASSWORD`, `DB_PORT`, `DB_USER`, `JWT_SECRET` (min 10 chars), `JWT_EXPIRES_IN` (seconds, default 3600), `SESSION_IDLE_TTL_SECONDS` (default 172800, sliding idle window of refresh sessions), `SWAGGER_ENABLED` (`'true'`/`'false'` only, default `true`, parsed to boolean; `false` skips `/swagger` via `http/swagger` `setupSwagger`). `SharedModule` re-exports `EnvModule`, so use cases can inject `EnvService`. `prisma.config.ts` and `docker-compose.yml` read the same `DB_*` names.

`CORS_ORIGINS` (optional, default empty) feeds `http/cors` `buildCorsOptions()`, called from `main.ts`. `validation/email.ts` exports `emailSchema` (trim → lowercase → email, max 254) used by all auth schemas.

Pool of the pg driver behind Prisma (`Database`, spec 069): `DB_POOL_MAX` (default 20; pg's own default is 10), `DB_POOL_IDLE_TIMEOUT_MS` (default 30000), `DB_POOL_CONNECTION_TIMEOUT_MS` (wait for a free connection, default 0 = no limit), `DB_STATEMENT_TIMEOUT_MS` (default 0 = off; sent as `statement_timeout` only when > 0). Empty strings fall back to the defaults. Keep `DB_POOL_MAX` × API instances under the server's `max_connections`. With `PERF_COUNT_QUERIES=1`, `QueryCounter` also records the highest `waitingCount` of the pool and `configure-app` exposes it as the `x-perf-pool-max-waiting` response header (a request with `x-perf-reset-pool: 1` zeroes it first); `perf:check` reads it for `maxPoolWaiting`.

Spec 056 adds `APP_ENVIRONMENT` (`production|staging|development`, default `development`), `VERSION_REPO_API`, `VERSION_REPO_APP` (`owner/name`, optional; empty disables the check), `GITHUB_TOKEN` (optional, read-only, never logged) and `VERSION_CHECK_TTL_SECONDS` (default 600).

`PERF_COUNT_QUERIES` (`'1'` enables, default off; spec 065): `Database` then calls `QueryCounter.enable()` (`db/QueryCounter.ts`, patches `pg.Client.prototype.query`, `begin()`/`end()` return the statements counted in between). Only the perf runner sets it. `http/configure-app` holds the app setup (CORS, body limit, URI versioning, `api` prefix, swagger) shared by `main.ts` and the perf runner.

Adding a variable: `envSchema` → `EnvService` getter (+ its test/fixtures) → `docker-compose.yml` `environment` → placeholder in `.env.example`. Values never go in source.

## Quote sources and scheduler (spec 104)

`@shared/infra/quotes/{brapi,finnhub,fx}` (tokens `IBrapiQuotes`, `IFinnhubQuotes`, `IFxRates`; types in `quotes/types.ts`): axios with a 5 s timeout, tokens from `EnvService` (`BRAPI_TOKEN`, `FINNHUB_TOKEN`, optional; a missing token throws `QuoteSourceUnavailableError`), ticker regex before any URL, 429/402/5xx/timeout mapped to `QuoteSourceLimitError`. brapi: the free plan takes ONE ticker per request, so `getQuotes` learns the limit from `QUOTES_PER_REQUEST_EXCEEDED` and chunks, a 404 (unknown ticker) is skipped, daily history on the free plan is 3 months (`3mo`); its currency endpoint needs a paid plan, so `FxRates` falls back to AwesomeAPI (no token). Finnhub: one call per symbol (`/quote`, `/search`). `@shared/infra/scheduler` (`IScheduler.cron(name, expression, timeZone, handler)`) wraps `@nestjs/schedule` (`ScheduleModule.forRoot()` in `SharedModule`) and logs handler failures. Env: `INVESTMENT_QUOTES_JOB_ENABLED`, `INVESTMENT_QUOTES_BRAPI_BATCH_SIZE` (20), `INVESTMENT_QUOTE_REFRESH_COOLDOWN_MS` (60000).

## Adding a wrapper

1. `shared/infra/<name>/types.ts` interface (+ `index.ts` impl, `index.test.ts`, `index.mocks.ts`).
2. Provide it in `SharedModule` (`{ provide: 'I<Name>', useClass }`) and add the token to `exports`.
3. Consumers `@Inject('I<Name>')`; never import the lib itself.

Logging: `logger.log(LogLevel.X, 'message', { module: 'ClassName', ...ctx })`. Never log passwords, hashes, tokens or full request bodies.
